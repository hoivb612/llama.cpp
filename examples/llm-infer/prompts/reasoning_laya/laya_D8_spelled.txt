# D8 SPELLED-NUMERAL PROBE TEST  (experiment B)
#
# Question: is there ANY readable signal inside a sentence encoder for the
# digit classes of D8? Laya cannot separate 585584 from 585594 because the two
# utterances are semantically identical and differ by one character, and
# tokenizers shred digit runs into pieces that destroy positional alignment.
#
# Hypothesis: spelled-out numerals are ordinary word tokens, so a probe phrased
# as "ends in eighty-four" may be readable where "585584" is not. There is a
# second, non-obvious reason to expect this to work better than it looks: the
# spelled form does NOT appear in the state (the phonebook holds digits), so
# unlike the failed "mentions the names Nicky, Tanya..." probe it cannot match
# the state instead of the reply. It sidesteps the rule-1 state-level trap.
#
# This file changes ONLY the LAYA_NOUL block. State, choice, prompts and the
# labels are identical to laya_D8_guarded.txt. The policy is neutralised to
# "* -> @choice" so the noul columns can be read without the guards firing.
#
# Read the result with: examples/llm-infer/laya/analyze_probes.py
#
# ---------------------------------------------------------------------------
# RESULT: REFUTED. Measured on Laya-Q8_0, 8 threads, 2026-10-04.
#
# No probe separates any class at any threshold. Best margin was s_585 on
# class 'a' at -0.107 (negative = no threshold exists).
#
# The failure is directional, not marginal. Every one of the 8 probes peaks on
# class 'a', including the 5 that do not target it:
#
#   probe    should peak on            actually peaks on
#   s_960    c (960564, 960194)        a (585584)   0.768 vs 0.614
#   s_849    c (849456)                a            0.645 vs 0.440
#   s_94     d (585594)                a -- and 'd' is its LOWEST class, 0.391
#
# s_84 / s_94 is a controlled pair: identical sentence, one word changed,
# disjoint target rows. Both produce the ranking a > z > b > c/d. Cross-probe
# correlation averages r=0.806, so 8 questions about different digit content
# are largely measuring one shared factor -- plausibly "does this reply
# confidently assert a number", which is a property of the 'a' rows' phrasing
# and has nothing to do with any probe's digits.
#
# Conclusion: spelling numerals out does not create readable digit signal. The
# encoder is not failing to parse digits; it is not representing them at all in
# a direction the scoring head can read. This closes the question for scorers
# -- the digit classes must be handled outside the model.
#
# What to do instead: prompts/reasoning/D8_extract.txt (generative extraction)
# + examples/llm-infer/laya/d8_ensemble.py (code-side lookup). That reaches
# 26/26 on exactly these digit classes.
#
# Do not re-run this with better wording. The result is not about wording.
# ---------------------------------------------------------------------------
